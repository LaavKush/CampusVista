## 📌 Overview
**CampusVista** is a digital campus navigation and services platform designed to help students and visitors efficiently navigate large campuses and access essential on-campus services.

The platform addresses challenges related to campus navigation, service discovery, and manual order handling by providing a unified and interactive system for both users and service providers.

---

## 🎯 Key Features
- 🧭 **Campus-Wide Navigation** – Locate academic blocks, hostels, and service areas  
- 🗺️ **Panoramic Campus Explorer** – Semi-3D navigation with interactive hotspots using Leaflet  
- 📍 **Real-Time Route Guidance** – Directions from the user’s current location  
- 🍽️ **Canteen Ordering System** – Place food orders directly through the platform  
- 🖨️ **Print Shop Services** – Submit print requests online  
- 🛠️ **Shop Management Interface** – Manage incoming orders for canteen and print shops  
- 🔐 **Secure Authentication** – Firebase Auth 2.0 for user access

---

## 🏗️ System Architecture
- **Frontend** handles navigation, service discovery, and order placement  
- **Leaflet maps** enable interactive campus exploration and routing  
- **Firebase** manages authentication and real-time data storage  
- **Shop Interface** allows vendors to manage and track service requests
